# Materiales de «Conversaciones que conectan»

*Programa de 12 semanas para relacionarte mejor, persuadir con ética y defenderte de la manipulación, practicando con inteligencia artificial* — Leo Vallmar

Instrucciones listas para copiar, casos y plantillas del libro. Edición de **noviembre de 2026**: las funciones, menús y edades de las herramientas de IA se comprobaron entonces. Lo que cambie después se anota en [CAMBIOS.md](CAMBIOS.md).

## Cómo usarlo sin saber programar
- Para copiar una instrucción: abre el archivo, busca la instrucción y copia el bloque gris (botón de copiar a la derecha).
- Para descargarlo todo: botón verde **Code** → **Download ZIP**, y descomprime el archivo.

## Antes de usar una herramienta
Comprueba su edad mínima y sus condiciones vigentes. Este libro es para adultos: Claude exige 18 años; las condiciones de ChatGPT para Europa piden al menos 13 años o la edad mínima de cada país, y permiso de padre, madre o tutor por debajo de 18 (comprobado en noviembre de 2026). El libro explica qué no escribir nunca en un chat.
